One-Hour Task Matcher – Design System
 
We have chosen earthy colours and clean fonts to give the platform a welcoming, community-focused feel.
1. Colors

We will use green and orange as the main colours to keep the design warm and consistent.

- Primary: `#E2692F` – Used for main buttons and important actions.
- Secondary: `#1B3A2D` – Used for headings and other elements.
- Background: `#FAF8F4` – Used as the main page background.
- Text: `#1F2A24` – Used for headings and regular text.
- Accent: `#E3EAD9` – Used for highlights and light backgrounds.
- Success: `#2E7D4F` – Used for successful messages.
- Error: `#C0392B` – Used for error messages.

2. Typography

We will use two fonts to keep the application readable and visually appealing.

- **Headings: Fraunces – for a friendly and distinctive look.
- Body Text: Inter – for clear and easy reading.
- H1:48px, Bold
- H2:32px, Semi Bold
- H3: 20px, Semi Bold
- Body: 16px, Regular
- Small Text: 14px, Regular
- Buttons: 16px, Medium

3. Shape and Spacing
- Rounded corners will be used for buttons, cards and input fields.
- Spacing will follow a simple 4px-based pattern.
- Light shadows will be used to separate cards from the background.
- Pages will have enough spacing to avoid a crowded appearance.


4. UI Components

We plan to create the following reusable components:

- Navbar: For navigation between pages.
- Button:For actions like finding, applying for and posting tasks.
- Card: To display task details and recommended matches.
- Input:For login, registration and task forms.
- Dropdown:To select skills and available time.
- Badge:To show skills and task status.
- Modal:To display additional details or confirmation messages.
